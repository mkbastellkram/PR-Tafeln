# Masterprompt-Ergänzung — Adaptive IFCN-PR-Tafelproduktion

Keine starren Pixelmasken verwenden. Jede Tafel wird vor der Verarbeitung layoutbewusst gescannt. Blockgrenzen werden anhand von Überschriften, Rahmenlinien, Weißräumen, Kartenkonturen, Höhenprofilachsen, Foto-Rändern, Legenden und Kontaktboxen erkannt.

Karte, Höhenprofil, Fotos, Legende und Kontakte werden je Tafel individuell und vollständig mit Sicherheitsrand extrahiert. Karten-Vollbild nutzt eine separate Highres-Quelle. Fotos werden als horizontaler Swipe-Slider ausgegeben.

Variante B ist verbindlich: Doppeltipp auf Karte öffnet direkt den Vollbildmodus.
